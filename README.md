# 🌿 生物特徵解碼器 (Bio-Trait Decoder)

這是一款專為 **國小四年級學生** 設計的線上互動式教學遊戲。透過「二分法」分類邏輯，引導學生利用自然科學課所學的生物特徵知識，進行解謎與分類挑戰。

## 🚀 立即開始遊戲
點擊下方連結即可開始挑戰：
👉 **[點擊這裡開始遊戲](https://weddy1225-blip.github.io/Science02-v2-/)**

---

## 🎮 遊戲特點
*   **純點擊操作**：針對教學現場設計，無需打字、上傳或生成圖片，適合觸控螢幕與平板教學。
*   **100 題完整題庫**：涵蓋植物構造（根莖葉）、動物分類（脊椎、繁殖、變態）、真菌類及生態環境四大領域。
*   **不重複出題機制**：利用瀏覽器 `localStorage` 技術，確保學生在完成全題庫 100 題前，不會重複遇到相同的生物。
*   **視覺友善設計**：採用綠色系視覺主題，營造自然科學的學習氛圍。

---

## 📚 教學目標 (符合四年級認知)
根據國小自然科學領域課程綱要設計，重點包含：
*   **植物類**：辨識根（軸根/鬚根）、莖（木本/草本）、葉（網狀脈/平行脈）的特徵與繁殖方式。
*   **動物類**：區分脊椎與無脊椎動物、繁殖方式（卵生/胎生/卵胎生）及發育過程（完全/不完全變態）。
*   **菌類與生態**：認識真菌特徵（孢子繁殖）以及生態系中生產者、消費者、分解者的角色。

---

## 🛠️ 技術實作
*   **開發語言**：HTML5, CSS3, JavaScript (Vanilla JS)。
*   **題庫管理**：100 題 JSON 格式陣列，每題包含 `id`、`name`、`trait` (正解) 與隨機誘答項。
*   **狀態紀錄**：使用 `Window.localStorage` 儲存 `used_bio_ids`，即便重整網頁也會記得已挑戰過的題目。

---

## 🚀 部署說明
1.  下載本專案的 `index.html` 檔案。
2.  將檔案上傳至 **GitHub Pages** 或任何網頁伺服器。
3.  開啟連結即可開始遊戲。
    *   **遊戲規則**：每局隨機抽取 6 題，每題 100 分。
    *   **結算系統**：結束後會顯示總分及每題的詳細對錯回顧。
